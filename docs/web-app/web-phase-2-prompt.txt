     * Leg 2: Credit (CR) -> Account #, Amount ($100.00), Post Balance ($5,100.00)
     * Render visual badge: "Double-Entry Invariant Checked: Net Zero Difference ($0.00)".

3. Transaction Holds Management Drawer (`/src/components/drawers/AccountHoldsDrawer.tsx`):
   - Connect to `GET /api/v1/holds?accountId={id}`.
   - Display active holds table: Hold ID, Amount, Reason (CardAuthPreCheck, AmlFraudReview, ChequeClearance, EscrowMilestoneLock), Expiry Countdown Timer, Status (Active, Released, Captured).
   - Action Buttons:
     * "Apply Hold": Modal collecting Amount, Reason, TTL (hours/days), calling `POST /api/v1/holds`.
     * "Release Hold": Button calling `PUT /api/v1/holds/{id}/release`.
     * "Capture Hold": Button calling `PUT /api/v1/holds/{id}/capture` (converts hold into posted ledger debit).

4. Dapper Report & Trial Balance Exporter (`/src/components/reports/TrialBalanceExporter.tsx`):
